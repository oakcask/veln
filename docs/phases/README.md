# Implementation Phases

This directory keeps implementation-phase plans and working notes.

## Read First

- [../reviews/2026-05-24-first-slice-gap-review.md](../reviews/2026-05-24-first-slice-gap-review.md)
  records current gaps that must be fixed before treating the first-slice gate

- [first-slice-implementation.md](first-slice-implementation.md) describes the

## Read When

- Use this directory when starting or reviewing implementation work.
- Use `docs/reviews/` before relying on a phase completion claim.
- Use `docs/discussions/` when you need the original decision rationale.
- Use `docs/reference/` when a decision has been promoted to stable reference
  material.
