# Documentation Navigation

Use this page after [README.md](README.md) when the first route is not obvious.
Choose one route and stop when the linked short page answers the question. Use
[navigation-full.md](navigation-full.md) only for navigation history or when the
routes below are not enough.

## Read First

- Current behavior: [specification/README.md](specification/README.md).
- Planned or accepted proposal work: [proposals/README.md](proposals/README.md).
- Rationale routes: [specification/source-decisions.md](specification/source-decisions.md).
- Document movement rules: [document-status.md](document-status.md).

## Choose One Route

  [navigation-full.md#documentation-maintenance](navigation-full.md#documentation-maintenance).

## Boundary Rules

- Current behavior pages under `specification/` win over proposal and
  review wording.
- Proposal text is not current behavior until the language specification also
  says so.
- Target state is decided only by
  [proposals/target-selection.md](proposals/target-selection.md); other
  proposal pages provide details after that route names them.
- A `*-full.md` file is a detail record. Open it only through the short page
  that names the relevant section.

## Skip Unless Needed

- Do not use this page when one of the top-level README's read-first links
  already matches the task.
- Do not open [navigation-full.md](navigation-full.md) before choosing one short
  route above.
- Do not open `*-full.md` files before a short route page names the relevant
  section.
