# Bibliography

This directory keeps durable source metadata and the claim-to-source map for
language-design rationale. Read it only when a decision record needs research
support or citation context.

## Read First

- [source-families.md](source-families.md): grouped source families by design
  topic.
- [claim-map.md](claim-map.md): design claims mapped to source-decision records
  and supporting references.
- [references.md](references.md): sanitized reference metadata.

## Read When

- Use `source-families.md` to find the research area behind a design topic.
- Use `claim-map.md` before changing the rationale in
  `../source-decisions/`.
- Use `references.md` only when exact source metadata is needed.
