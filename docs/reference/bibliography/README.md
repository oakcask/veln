# Bibliography

This directory keeps durable source metadata and the claim-to-source map for
language-design rationale. Read it only when a decision record needs research
support or citation context.

## Read First

- [source-families.md](source-families.md): route to grouped source families
  by design topic.
- [claim-map.md](claim-map.md): route to design claims mapped to
  source-decision records and supporting references.
- [references.md](references.md): route to sanitized reference metadata.

## Fast Routes

- Known design topic: use [source-families.md](source-families.md), then one
  selected family in the full source-family record.
- Known claim or decision record: use [claim-map.md](claim-map.md), then the
  selected claim details.
- Known citation key or title: use [references.md](references.md), then the
  selected reference entry.

## Read When

- Use [source-families.md](source-families.md) to find the research area
  behind a design topic; open
  [source-families-full.md](source-families-full.md) only for the selected
  family.
- Use [claim-map.md](claim-map.md) before changing the rationale in
  `../source-decisions/`; open
  [claim-map-full.md](claim-map-full.md) only for the selected claim details.
- Use [references.md](references.md) only when exact source metadata is needed;
  open [references-full.md](references-full.md) only for the selected source.

## Skip Unless Needed

- Do not use bibliography pages as current language behavior; start in
  `../language/` for behavior questions.
- Do not open full bibliography records before a short page identifies the
  selected source family, claim, or reference.
