# Bibliography Claim Map

This is the routing page for claims mapped to source-decision records and
supporting references. Use it to choose the relevant claim before opening the
full bibliography notes.

  claims.

- [claim-map-full.md](claim-map-full.md): full claim-to-source mapping.
