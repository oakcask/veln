# Bibliography Source Families

This page routes grouped research-source families. Use it when choosing which
source family supports a design claim.

## Read First

- Contract and specification languages, effects and diagnostics, syntax and
  partial programs, comparative evaluation, module metadata, decision capture,
  doctests, repair, regression selection, and functional containers are the
  current families.
- Open the full page only for the family behind the decision or claim you are
  changing.

## Read When

- Source-family membership by topic:
  [source-families-full.md](source-families-full.md).
- Claim-to-decision routing before editing rationale:
  [claim-map.md](claim-map.md).
- Exact source metadata: [references.md](references.md).

## Skip Unless Needed

- Do not read this bibliography route for implemented behavior questions; use
  [../../specification/README.md](../../specification/README.md) first.
