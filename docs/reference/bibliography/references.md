# Bibliography References

This page routes sanitized reference metadata promoted from the working
bibliography cache.

## Read First

- Use source identifiers from decision records or claim maps to find exact
  reference metadata in the full page.
- Keep design behavior in `../../specification/` and rationale in
  `../source-decisions/`; this page is only for citation metadata.

## Read When

- Exact metadata for a known source identifier:
  [references-full.md](references-full.md).
- Topic grouping before choosing a source identifier:
  [source-families.md](source-families.md).
- Claim and source-decision relationships: [claim-map.md](claim-map.md).

## Skip Unless Needed

- Do not open the full metadata list when a source-decision record already
  contains enough rationale for the task.
