# HTTP/2 Standard Library Completion and Fixture Retirement

Status: superseded

This premature completion record is retained as a stable route for older
implemented-slice references. It is not completion evidence.

Reusable connection, stream, HPACK, receive, send, flow-control, and output
behavior is standard-owned and documented in
[`http2.md`](../../specification/http2.md). The aggregate fixture was removed,
but its item-level replacement evidence was not established before removal.

The remaining evidence work is tracked by the active
[`http2-sans-io-protocol-core`](../../proposals/http2-sans-io-protocol-core.md)
proposal. Do not cite this page or fixture deletion as proof that every
historical helper invocation, stdout value, or emitted-byte assertion has a
checked replacement.
