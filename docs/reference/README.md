# Reference

Stable reference material lives here. Read these files when you need the
current specification shape without the historical discussion that led to it.

## Read First

- [grammar.md](grammar.md) is the canonical first-slice source grammar.
- [bibliography/source-families.md](bibliography/source-families.md) groups the
  research references that support design decisions.

## Read When

- Use `docs/discussions/` for rationale and dated decision history.
- Use `docs/phases/` for implementation plans and completion notes.
- Use `docs/reviews/` for current implementation gaps and verification
  findings.
